Data types are defined in the `HealthDataType` enum, and each type has a default `HealthDataUnit`.

- **iOS** supports HealthKit-specific types such as workouts, ECG, sleep stages, nutrition, and many biometrics.
- **Android** supports Health Connect types including steps, heart rate, sleep, speed and distance, nutrition, hydration, menstruation flow, and more.

## Platform type lists

The plugin exposes a list of the supported types for each platform:

```dart
// iOS
const List<HealthDataType> dataTypesIOS = [...];

// Android
const List<HealthDataType> dataTypesAndroid = [...];
```

Use them for quick testing or to build permission requests.

## Units

Each type maps to a default unit through `dataTypeToUnit`, for example `HEART_RATE` → `BEATS_PER_MINUTE` and `WEIGHT` → `KILOGRAM`. When you read data, you can optionally request a preferred unit per type.

```dart
final unit = dataTypeToUnit[HealthDataType.HEART_RATE]; // BEATS_PER_MINUTE
```

## Sleep and headache categories

For the categorical sleep and headache types, values are converted to minutes based on the `dateFrom`/`dateTo` interval.

## Workouts

A workout is a `HealthDataType.WORKOUT` data point with a `WorkoutHealthValue`, which may include:

- `workoutActivityType`
- `totalEnergyBurned` (+ unit)
- `totalDistance` (+ unit)
- `totalSteps` (+ unit)

An additional `workoutSummary` is attached when available.

## Special data

| Type | Handling |
| --- | --- |
| ECG (`ELECTROCARDIOGRAM`) | Parses the voltage series, average heart rate, sampling frequency, and classification. |
| Nutrition (`NUTRITION`) | Supports a wide set of macro- and micronutrients. |
| Menstruation flow (`MENSTRUATION_FLOW`) | Normalizes platform-specific values. |
